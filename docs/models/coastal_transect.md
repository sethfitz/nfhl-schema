# CoastalTransect

The S_Cst_Tsct_Ln table contains information about the Coastal Transect Lines
within the Flood Risk Project area, if applicable. The spatial elements
representing coastal transects are lines that generally extend from offshore all
the way across the coastal floodplain. Transects can also extend seaward when
wave runup modeling is used to determine coastal flood hazards. This information
is needed for the Transect Locator Map table and Coastal Transect Parameters
table in the FIS Report. Published as layer 15 of the NFHL MapServer, which also
carries `GFID`, `GlobalID`, `OBJECTID`, `SHAPE.STLength()`; the reference does
not define them, so they are optional and validated only by type.
