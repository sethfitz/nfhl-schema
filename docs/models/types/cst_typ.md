# CstTyp

Values of `D_Cst_Typ` that apply to the FIRM Database, each as the data stores
it. Used by `S_Cst_Tsct_Ln.CSTLN_TYP`.

## Values

- `Open Coast` - Code `1000`.
- `Sheltered Waters` - Code `2000`.
- `Combined Open Coast and Sheltered Waters` - Code `3000`.
- `NP` - Code `NP`.

- [`CoastalTransect`](../coastal_transect.md)
