# CstStruct

Values of `D_Cst_Struct` that apply to the FIRM Database, each as the data
stores it. Used by `S_Gen_Struct.CST_STRUCT`.

## Values

- `Beach Stabilization Structure` - Code `1000`.
- `Coastal Armoring Structure` - Code `2000`.
- `Miscellaneous Structure` - Code `3000`.
- `NP` - Code `NP`.

## Used By

- [`GeneralStructure`](../general_structure.md)
