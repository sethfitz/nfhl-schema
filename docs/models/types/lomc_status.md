# LOMCStatus

Values of `D_LOMC_Status` that apply to the FIRM Database, each as the data
stores it. Used by `S_LOMR.STATUS`.

## Values

- `Superseded` - Code `1000`.
- `Revalidated` - Code `1010`.
- `Incorporated` - Code `1020`.
- `Redetermined` - Code `1030`.
- `Effective` - Code `1040`.
- `NP` - Code `NP`.
