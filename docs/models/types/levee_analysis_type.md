# LeveeAnalysisType

Values of `D_Levee_Analysis_Type` that apply to the FIRM Database, each as the
data stores it. Used by `S_Levee.LEV_AN_TYP`.

## Values

- `Natural Valley` - Code `NV`.
- `Structural-Based Inundation` - Code `SBI`.
- `Overtopping` - Code `OVR`.
- `Freeboard Deficient` - Code `FD`.
- `Sound Reach` - Code `SR`.
- `BFE Below Toe` - Code `BBT`.
- `Not Hydraulically Significant` - Code `NHS`.
- `Other` - Code `OTH`.
- `NP` - Code `NP`.
