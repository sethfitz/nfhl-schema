# LnTyp

Values of `D_Ln_Typ` that apply to the FIRM Database, each as the data stores
it. Used by `S_Fld_Haz_Ln.LN_TYP`.

## Values

- `SFHA / Flood Zone Boundary` - Code `2034`.
- `Limit Lines` - Code `1010`.
- `Other Boundary` - Code `1020`.
- `Flowage Easement Boundary` - Code `2050`.
