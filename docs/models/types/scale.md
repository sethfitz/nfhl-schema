# Scale

Values of `D_Scale` that apply to the FIRM Database, each as the data stores it.
Used by `S_LOMR.SCALE`, `S_FIRM_Pan.SCALE`.

## Values

- `6000` - Code `1000`.
- `12000` - Code `1010`.
- `24000` - Code `1020`.
- `10000` - Code `2000`.

## Used By

- [`FirmPanel`](../firm_panel.md)
- [`Lomr`](../lomr.md)
