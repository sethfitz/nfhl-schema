# VDatum

Values of `D_V_Datum` that apply to the FIRM Database, each as the data stores
it. Used by `S_Fld_Haz_Ar.V_DATUM`, `S_BFE.V_DATUM`, `S_XS.V_DATUM`.

## Values

- `MSL` - Mean Sea Level. Code `MSL`.
- `NAVD88` - North American Vertical Datum 1988. Code `NAVD88`.
- `NGVD29` - North American Geodetic Vertical Datum 1929. Code `NGVD29`.
- `LOCAL TIDAL DATUM` - Local Tidal Datum. Code `TIDAL`.
- `MLLW` - Mean Lower Low Water Datum. Code `MLLW`.
- `MLW` - Mean Low Water Datum. Code `MLW`.
- `GUVD04` - Guam Vertical Datum of 2004. Code `GUVD04`.
- `NMVD03` - Northern Marianas Vertical Datum of 2003. Code `NMVD03`.
- `PRVD02` - Puerto Rico Vertical Datum of 2002. Code `PRVD02`.
- `VIVD09` - Virgin Islands Vertical Datum of 2009. Code `VIVD09`.
- `NP` - Code `NP`.
