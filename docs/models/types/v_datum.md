# VDatum

Values of `D_V_Datum` that apply to the FIRM Database, each as the data stores
it. Used by `S_Fld_Haz_Ar.V_DATUM`.

## Values

- `MSL` - Mean Sea Level. The reference codes it `MSL`.
- `NAVD88` - North American Vertical Datum 1988. The reference codes it `NAVD88`.
- `NGVD29` - North American Geodetic Vertical Datum 1929. The reference codes it `NGVD29`.
- `LOCAL TIDAL DATUM` - Local Tidal Datum. The reference codes it `TIDAL`.
- `MLLW` - Mean Lower Low Water Datum. The reference codes it `MLLW`.
- `MLW` - Mean Low Water Datum. The reference codes it `MLW`.
- `GUVD04` - Guam Vertical Datum of 2004. The reference codes it `GUVD04`.
- `NMVD03` - Northern Marianas Vertical Datum of 2003. The reference codes it `NMVD03`.
- `PRVD02` - Puerto Rico Vertical Datum of 2002. The reference codes it `PRVD02`.
- `VIVD09` - Virgin Islands Vertical Datum of 2009. The reference codes it `VIVD09`.
- `NP` - The reference codes it `NP`.
