# PanelTyp

Values of `D_Panel_Typ` that apply to the FIRM Database, each as the data stores
it. Used by `S_FIRM_Pan.PANEL_TYP`.

## Values

- `Countywide, Panel Printed` - Code `1000`.
- `Countywide, Not Printed` - Code `1010`.
- `Community Based, Panel Printed` - Code `1020`.
- `Community Based, Not Printed` - Code `1030`.
- `Unmapped Community` - Code `1040`.
- `Statewide, Panel Printed` - Code `1050`.
- `Statewide, Not Printed` - Code `1060`.

## Used By

- [`FirmPanel`](../firm_panel.md)
