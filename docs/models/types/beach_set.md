# BeachSet

Values of `D_BeachSet` that apply to the FIRM Database, each as the data stores
it. Used by `S_Cst_Tsct_Ln.BEACH_SET`.

## Values

- `Cobble, Gravel, Shingle, or Mixed Grain Sized Beach and Berms` - Code `1050`.
- `Erodible Coastal Bluffs` - Code `1020`.
- `Non-Erodible Coastal Cliffs and Bluffs` - Code `1030`.
- `Sandy Beach Backed by Low Sand Berm or High Sand Dune Formation` - Code `1000`.
- `Sandy Beach Backed by Shore Protection Structures` - Code `1010`.
- `Tidal Flats and Wetlands` - Code `1040`.
- `NP` - Code `NP`.
