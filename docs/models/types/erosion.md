# Erosion

Values of `D_Erosion` that apply to the FIRM Database, each as the data stores
it. Used by `S_Cst_Tsct_Ln.EROS_METH`.

## Values

- `Not Applied` - Code `1010`.
- `Dune Removal` - Code `1020`.
- `Dune Retreat` - Code `1030`.
- `K-D` - Code `1040`.
- `MK-A` - Code `1050`.
- `SBEACH` - Code `1060`.
- `Other` - Code `9000`.
- `NP` - Code `NP`.
