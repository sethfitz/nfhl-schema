# LengthUnits

Values of `D_Length_Units` that apply to the FIRM Database, each as the data
stores it. Used by `S_Fld_Haz_Ar.LEN_UNIT`.

## Values

- `Centimeters` - Coded value `CM`.
- `Feet` - Coded value `FT`.
- `Inches` - Coded value `IN`.
- `Kilometers` - Coded value `KM`.
- `Meters` - Coded value `M`.
- `Miles` - Coded value `MI`.
- `Millimeters` - Coded value `MM`.
- `U.S. Survey Feet` - Coded value `USFT`.
- `NP` - Coded value `NP`.

## Used By

- [`FloodHazardZone`](../flood_hazard_zone.md)
